Parameters

A parameter turns a fixed value in this report into a control on the dashboard. Write {{key}} where the value goes — in the SQL, or as a filter value on the Build tab — and declare it here. Reports on the same dashboard that use the same key share one control, which is how nine tiles move together. Preview runs with the defaults below.
