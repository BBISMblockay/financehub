Testing SILO's Klaviyo integration

For the Klaviyo app review team. Everything below can be done in a test workspace with sample data; nothing is sent to your subscribers at any point.

1. What the app does

SILO is an operations and reporting platform. Companies connect the tools they already use — their store, ad platforms, bank, email and SMS — and SILO puts the numbers from all of them on one set of reports.

The Klaviyo integration is read-only reporting. SILO pulls campaign, flow and message statistics on a schedule and shows them beside the company's other marketing. It never sends an email or an SMS, never creates or edits a campaign, flow, list, segment or profile, and never writes anything back to Klaviyo.

2. Getting a test login

No credentials appear on this page. Email support@get-silo.com with the subject Klaviyo app review and the email address you want access on. We create a reviewer account on an empty test workspace and reply with a sign-in link, usually the same business day. The account is removed when the review closes.

The test workspace starts with no integrations connected, so the install flow below is exercised from the beginning. Tell us if you would rather test against a workspace that already has a store connected, so the attribution surfaces have sales to sit beside.

3. Installing from Klaviyo (the install URL)

This is the flow behind the app listing's install button, and it works when hit cold, by someone who is not signed in to SILO.

  1. Open the install URL: https://get-silo.com/v2/klaviyo-install.html
  2. If you are not signed in, SILO asks you to sign in and returns you to this page. If your account belongs to more than one workspace, it asks which one to connect.
  3. The page names the workspace being connected and lists what the app will read. Choose Continue to Klaviyo.
  4. Klaviyo's own consent screen opens. Approve it with the account you are testing.
  5. Klaviyo returns you to SILO, which confirms the connection and shows it on the workspace's Integrations page.

4. Installing from inside SILO

The same connection can be started by an existing user:

  1. Sign in and open Settings → Integrations.
  2. Find the Klaviyo card and choose Connect.
  3. Approve the Klaviyo consent screen. You land back on Integrations with the account name and its connection status shown on the card.

5. Permissions requested, and why

ScopeWhat SILO uses it for
campaigns:readCampaign names, channel, send time and status, so a message can be named in a report rather than shown as an ID.
flows:readThe same for flows and their messages.
metrics:readDelivery, open, click, unsubscribe, conversion and revenue statistics — the numbers the reports are made of. It also reads the account's conversion metrics, so a figure can say which event it counted.
lists:readList names, used to label audience figures.
segments:readSegment names, for the same reason.

All five are read scopes. SILO requests no write scope of any kind, so no action in SILO can change anything in Klaviyo. If a write feature is ever added it will need a new scope and a fresh consent from the account owner.

6. What happens after you connect

  • A first sync starts immediately on connect, so there is something to look at within a minute or two rather than the next day.
  • After that the sync runs daily, with a second catch-up run the same day if the first does not complete. Each run overwrites a trailing window, so re-running changes nothing except to bring the numbers up to date.
  • A new account can be backfilled further back on request.
  • A test account with sample data and no send history will show campaigns and flows with zero or very small numbers. That is expected and is enough to confirm the flow of data.

7. Where the data appears

WhereWhat to look for
Settings → IntegrationsThe Klaviyo card: the connected account, when it last synced, and whether the last sync succeeded.
Marketing → Performance → Email & SMSOne row per message, with the vendor, channel, the window the figures were measured over, sends, orders and the revenue Klaviyo credits.
Marketing → Marketing ReportThe campaigns and flows cards for the reported period, beside the rest of the week's marketing.
Marketing → Silo AttributionEmail and SMS as channels in the attribution model, with SMS sending cost listed as a cost rather than as ad spend.
ReportsReady-made Klaviyo reports — message performance, a daily trend and a flow breakdown — runnable over any date range.

Two things on those screens are deliberate and may look unusual on review. Klaviyo reports a campaign as a total over a measurement window rather than per day, so every Klaviyo figure names the window it covers instead of borrowing the report's dates. And statistics measured against different conversion metrics stay on separate rows, because they count different events and adding them would be wrong.

8. Disconnecting

On Settings → Integrations, the Klaviyo card offers Disconnect. That revokes SILO's stored token immediately and stops all syncing. Uninstalling the app from Klaviyo's side has the same effect: the token stops working, and SILO's next sync records the connection as needing re-authorisation rather than retrying endlessly.
