Amazon Ads preview

The Integrations card for Amazon Ads, lifted live out of v2/integrations.html. Not a copy — if the card changes there, it changes here. Nothing on this page is wired to anything: Connect does nothing, and there are no connections to list because this page reads no database.

Why the live card is hidden

The card is already in v2/integrations.html and has to stay there: Login with Amazon redirects the browser back to that page, so that is where the connection lands. It is hidden until the deployment says Amazon is configured — probeAmazonOauth() asks amazon-oauth-start whether an AMAZON_ADS_CLIENT_ID exists, and only then reveals it. An existing connection reveals it too, so failing closed can never hide a live one.

Still owed before anyone can connect:

  • An approved Amazon Ads API application and a Login with Amazon client
  • supabase/migrations/20261120050000_amazon_ads_connection.sql applied
  • amazon-oauth-start, amazon-oauth-callback, test-ad-platform-connection and ad-platform-sync-run deployed
  • AMAZON_ADS_CLIENT_ID and AMAZON_ADS_CLIENT_SECRET set
